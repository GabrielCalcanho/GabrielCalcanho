Sou desenvolvedor **Full Stack em formação**, focado no ecossistema **JavaScript/TypeScript**. Do lado do front-end trabalho com **React, Redux, HTML e CSS**; do lado do back-end estudo **Node.js, Express e NoSQL**, além de boas práticas com **Design Patterns**.
